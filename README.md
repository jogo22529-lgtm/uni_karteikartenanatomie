# Anatomie Karteikarten

Karteikarten zum Skript „Sportmedizin – Anatomie 1 (Zimmermann)“.

- App: `index.html` einfach im Browser öffnen (keine Installation).
- Karten bearbeiten: `cards.txt` (Format `Kategorie|Vorderseite|Rückseite`), danach `python3 build.py` ausführen.
- Falsch beantwortete Karten werden wiederholt, bis alle richtig sind; der Fortschritt (in %) wird im Browser gespeichert.
